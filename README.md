# Aetherion Official

A dark, responsive static website for your Minecraft Bedrock Edition projects.

## Current sections
- Addons
- Texture Packs
- Maps
- Skins

All categories intentionally start empty.

## Files
- `index.html` — homepage
- `category.html` — reusable category page
- `style.css` — dark visual design
- `script.js` — mobile menu and category handling
- `assets/logo.png` — your supplied Aether Clan logo

## Adding projects
This first version is a static frontend. To publish projects, create project cards/pages and connect their download buttons to your `.mcaddon`, `.mcpack`, `.mcworld`, or other files.

For a larger version, this can be upgraded to a real upload/admin system with project management, search, versioning, screenshots, download counters, and a database/storage backend.
